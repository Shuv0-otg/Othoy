# অথৈ

ভর্তি বাংলার ফ্ল্যাশকার্ড আর ছোট পরীক্ষা। ১,৬১৯টি প্রশ্ন, ১৩টি বিষয়, একটি মিশ্র এলোমেলো পরীক্ষা।

সব ফাইল একই ফোল্ডারে রাখুন। `index.html` খুললেই শুরু।

- `index.html` — হোম (সব বিষয় + মিশ্র পরীক্ষা)
- `athoi-mixed.html` — সব বিষয় থেকে মিশ্র এলোমেলো পরীক্ষা
- `athoi-<বিষয়>.html` — প্রতিটি বিষয়ের আলাদা অ্যাপ
